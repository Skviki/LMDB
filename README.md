# LMDB

LMDB is a program designed for creating `.deb` packages.

Of course, there are already programs that can perform a similar task, but the main focus of LMDB is **simplicity**.

If you just need to test something or create a `.deb` package for a small project where having lots of configuration options is not important, you may like this program. LMDB also provides a graphical user interface (GUI).

## Important

The project was developed on **Linux Mint** and has not been tested on other Debian-based distributions. Therefore, I cannot guarantee that the program will work correctly on all Debian-based systems.

## Technologies Used

- C#
- GTK
- FFmpeg
